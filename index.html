Chiave API YouTube

Resta solo nel tuo browser (localStorage).

Come crearla (gratis, 3 minuti)
  1. Vai su console.cloud.google.com e crea un progetto.
  2. "API e servizi" → "Libreria" → cerca YouTube Data API v3 → Abilita.
  3. "Credenziali" → "Crea credenziali" → "Chiave API".
  4. Consigliato: limita la chiave alla sola YouTube Data API v3.
  5. Incollala qui sopra.

Quota gratuita: 10.000 unità/giorno. Ogni ricerca ne costa ~101, quindi circa 95 ricerche al giorno.
